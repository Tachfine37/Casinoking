Build a stunning, production-ready casino & gambling blog website using Next.js 14 
(App Router) + Tailwind CSS. Articles and affiliate data are stored in Supabase 
(PostgreSQL). The site must be fully SEO-optimized and handle hundreds of articles.

---

## SUPABASE SETUP

Create a /lib/supabase.js client using @supabase/supabase-js.
Read NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY from .env.local

Database schema to create in Supabase:
```sql
CREATE TABLE articles (
  id            UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  title         TEXT        NOT NULL,
  slug          TEXT        UNIQUE NOT NULL,
  excerpt       TEXT,
  content       TEXT,
  category      TEXT,
  image         TEXT,
  author        TEXT,
  author_bio    TEXT,
  author_avatar TEXT,
  focus_keyword TEXT,
  meta_description TEXT,
  date          DATE,
  read_time     TEXT,
  featured      BOOLEAN     DEFAULT false,
  published     BOOLEAN     DEFAULT false,
  created_at    TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE affiliates (
  id          UUID    PRIMARY KEY DEFAULT gen_random_uuid(),
  name        TEXT    NOT NULL,
  logo        TEXT,
  rating      NUMERIC(2,1),
  bonus       TEXT,
  description TEXT,
  link        TEXT,
  badge       TEXT,
  position    INTEGER DEFAULT 0,
  active      BOOLEAN DEFAULT true
);
```

Seed the tables with 6 sample articles and 4 sample affiliates directly via 
Supabase JS client in a /lib/seed.js file.

Sample article structure:
- slug: "best-online-casinos-2025"
- focus_keyword: "best online casinos 2025"
- title: "Best Online Casinos in 2025: Expert Picks & Reviews"
- category: one of: Casino Reviews, Slots, Poker, Sports Betting, Bonuses, Strategy
- image: use Unsplash URLs (gambling/casino themed)
- content: proper multi-paragraph HTML with H2 subheadings

## SEO REQUIREMENTS

Every article page must have:
- <title>{title} | CasinoKing</title>
- <meta name="description" content={meta_description}>
- <link rel="canonical" href={fullUrl}>
- og:title, og:description, og:image, og:type="article"
- twitter:card, twitter:title, twitter:description, twitter:image
- JSON-LD Article schema:
  {
    "@context": "https://schema.org",
    "@type": "Article",
    "headline": title,
    "image": image,
    "datePublished": date,
    "author": { "@type": "Person", "name": author },
    "description": meta_description,
    "keywords": focus_keyword
  }
- One H1 per page
- Images with descriptive alt text
- Semantic HTML throughout

Category and homepage also get proper title + description + OG tags.

---

## DATA FETCHING RULES

- Article list pages: fetch from Supabase with .select() filtering published = true
- Pagination: use .range() for 9 articles per page
- Category filter: .eq('category', category)
- Single article: .eq('slug', slug).single()
- Use generateStaticParams for all [slug] and [category] routes
- Use revalidate = 3600 (ISR — pages rebuild every hour automatically)
  This means new articles added to Supabase go live within 1 hour without redeployment
